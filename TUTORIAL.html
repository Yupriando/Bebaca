Sistem Operasi

Tutorial ini cocok untuk Windows 10/11, macOS, dan Linux.

Tool Versi Download
Node.js (untuk backend) ≥ 18 nodejs.org
Flutter SDK (untuk frontend) ≥ 3.7 flutter.dev
Android Studio (untuk emulator Android) Latest developer.android.com
Git Any git-scm.com
VS Code Opsional Any code.visualstudio.com

Cek apakah sudah terinstall:

Terminal / PowerShell 
node --version    # Harusnya: v18.x.x atau lebih
flutter --version # Harusnya: Flutter 3.7.x atau lebih
git --version      # Harusnya: git version 2.x.x
1

Setup SupabaseDatabase + Auth (gratis, sekali saja)

1

Buat Akun & Project Supabase

Buka supabase.com → Sign Up → New Project → isi nama project dan password database.

2

Jalankan Schema & Seed SQL

Di Supabase Dashboard → SQL Editor → paste dan jalankan file-file ini secara berurutan:

Urutan SQL 
# 1. Schema utama (tabel, index, RLS)
backend/supabase/schema.sql

# 2. Data awal (huruf, dongeng)
backend/supabase/seed.sql

# 3. Migrasi (jalankan satu per satu)
backend/supabase/migrations/001_story_video.sql
backend/supabase/migrations/002_lesson_content.sql
backend/supabase/migrations/003_premium.sql
backend/supabase/migrations/004_materi_dongeng.sql  # Materi baru!
3

Salin API Keys

Supabase Dashboard → Project Settings → API → salin:

  • Project URL → untuk SUPABASE_URL
  • anon public key → untuk SUPABASE_ANON_KEY
  • service_role secret key → untuk SUPABASE_SERVICE_ROLE_KEY
4

Matikan Verifikasi Email Disarankan untuk dev

Authentication → Providers → Email → matikan "Confirm email" supaya tidak perlu verifikasi saat testing.

2

Jalankan BackendNode.js + Express API Server

1

Masuk ke folder backend & isi .env

PowerShell / Terminal 
cd backend

# Salin file contoh .env
copy .env.example .env    # Windows
cp .env.example .env      # Mac/Linux

Buka file backend/.env dan isi nilai-nilai ini:

.env 
SUPABASE_URL=https://xxxxxx.supabase.co
SUPABASE_ANON_KEY=sb_publishable_xxxxx
SUPABASE_SERVICE_ROLE_KEY=sb_secret_xxxxx

PORT=3000
CORS_ORIGIN=*
APP_URL=http://localhost:3000

# Midtrans (opsional - untuk pembayaran nyata)
MIDTRANS_SERVER_KEY=SB-Mid-server-xxxxx
MIDTRANS_CLIENT_KEY=SB-Mid-client-xxxxx
MIDTRANS_ENV=sandbox
2

Install dependencies & jalankan

Terminal 
npm install
npm run dev

Jika berhasil, terminal akan menampilkan:

Output 
Bebaca API berjalan di http://localhost:3000
Dokumentasi Swagger: http://localhost:3000/docs
3

Verifikasi backend berjalan

Buka browser dan cek URL ini:

URLHasil yang Diharapkan
http://localhost:3000/health{"status":"ok"}
http://localhost:3000/health/db{"ok":true,...}
http://localhost:3000/docsHalaman Swagger UI
⚠️

Jangan tutup terminal backend!

Backend harus terus berjalan selama kamu menggunakan aplikasi. Buka terminal terpisah untuk Flutter.

3

Jalankan FlutterAplikasi mobile/web

1

Masuk ke folder frontend & install packages

Terminal Baru 
cd frontend
flutter pub get
2

Pilih cara menjalankan

PlatformPerintahCatatan
Emulator Android flutter run Backend otomatis di 10.0.2.2:3000
HP Android (WiFi sama) flutter run --dart-define=API_BASE_URL=http://IP_PC:3000 Cari IP PC: ipconfig
Web browser flutter run -d chrome Backend di localhost:3000
Windows desktop flutter run -d windows Backend di localhost:3000
3

Izin jaringan Android Wajib

Edit file frontend/android/app/src/main/AndroidManifest.xml — tambahkan di dalam tag <manifest>:

AndroidManifest.xml 
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.RECORD_AUDIO"/>
<queries>
  <intent><action android:name="android.speech.RecognitionService"/></intent>
  <intent><action android:name="android.intent.action.TTS_SERVICE"/></intent>
  <!-- Untuk url_launcher (Google Login & Midtrans) -->
  <intent><action android:name="android.intent.action.VIEW"/></intent>
</queries>

<!-- Di dalam <application> -->
android:usesCleartextTraffic="true"  <!-- Hapus saat produksi -->
✅

Aplikasi berhasil jalan!

Landing Page → Buat Akun → Login → Main Menu. Selamat mencoba semua fitur Bebaca!

4

Setup Login Google BaruLewat Supabase Google OAuth

ℹ️

Tanpa Google Login pun app tetap berjalan

Login email/password tetap bekerja normal. Google Login adalah fitur tambahan.

1

Buat Google OAuth Client ID

1. Buka console.cloud.google.com

2. Buat project baru atau pilih yang ada

3. APIs & Services → Credentials → Create Credentials → OAuth Client ID

4. Application type: Web application

5. Authorized redirect URIs — tambahkan:

Redirect URI 
https://PROJECT-ID.supabase.co/auth/v1/callback

6. Salin Client ID dan Client Secret

2

Aktifkan di Supabase

Supabase Dashboard → Authentication → Providers → Google → Enable

Isi Client ID dan Client Secret dari langkah 1.

3

Coba Login Google

Di aplikasi Flutter: Login Page → tombol "Lanjutkan dengan Google" → browser terbuka → login dengan akun Google → kembali ke app.

⚠️

Catatan untuk Mobile

Login Google membuka browser eksternal. Setelah selesai, pengguna perlu kembali manual ke aplikasi dan login ulang menggunakan email/password yang sudah terdaftar via Google (atau gunakan link penuh dengan deep link scheme).

5

Setup Midtrans Payment BaruGateway pembayaran Indonesia

💡

Tanpa Midtrans, mode simulasi tetap aktif

Jika MIDTRANS_SERVER_KEY tidak diisi, tombol Langganan akan langsung mengaktifkan premium tanpa pembayaran (untuk testing).

1

Daftar Midtrans

Buka dashboard.midtrans.com → daftar akun → pilih Sandbox untuk testing.

2

Ambil API Keys

Midtrans Dashboard → Settings → Access Keys → salin:

  • Server Key → MIDTRANS_SERVER_KEY di .env
  • Client Key → MIDTRANS_CLIENT_KEY di .env
3

Setup Notification URL (Webhook)

Midtrans harus bisa mengirim notifikasi ke backend kamu setelah pembayaran berhasil.

Untuk lokal: gunakan ngrok untuk tunnel:

Terminal 
ngrok http 3000
# Salin URL yang diberikan, contoh: https://abc123.ngrok.io

Midtrans Dashboard → Settings → Configuration → Payment Notification URL:

Notification URL 
https://abc123.ngrok.io/api/payment/notification

Untuk produksi: ganti dengan URL server yang sudah di-deploy.

4

Isi .env dan restart backend

.env 
MIDTRANS_SERVER_KEY=SB-Mid-server-xxxxxxxxxxxx
MIDTRANS_CLIENT_KEY=SB-Mid-client-xxxxxxxxxxxx
MIDTRANS_ENV=sandbox  # Ganti ke "production" saat live

Lalu restart backend: npm run dev

TroubleshootingMasalah umum dan solusinya

MasalahSolusi
Backend tidak jalan / port sudah dipakai Ganti PORT di .env, atau matikan proses lain: netstat -ano | findstr 3000
Flutter: "Tidak bisa terhubung ke server" Pastikan backend sudah jalan. Cek http://localhost:3000/health
Cleartext HTTP not permitted (Android) Tambahkan android:usesCleartextTraffic="true" di AndroidManifest
Login Google tidak bekerja Cek Supabase Google Provider sudah diaktifkan dan redirect URI benar
Midtrans: "Gagal membuat transaksi" Pastikan MIDTRANS_SERVER_KEY terisi benar dan format "SB-Mid-server-..."
Premium tidak aktif setelah bayar Cek webhook URL di Midtrans Dashboard. Gunakan ngrok untuk localhost.
Health/db: "hint: Jalankan migrasi" Jalankan semua file migration 001-004 di Supabase SQL Editor
url_launcher tidak bisa compile Jalankan flutter pub get di folder frontend
